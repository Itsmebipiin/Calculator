# 🧮 Calculator

A simple and responsive **web-based calculator** built using **HTML, CSS, and JavaScript**.

This was one of my early web development projects and helped me practice DOM manipulation, event handling, and basic JavaScript logic.

## 🚀 Live Demo

👉 [Try the Calculator](https://calculator-seven-tau-69.vercel.app/)

## ✨ Features

- Basic arithmetic operations
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Percentage calculation
- Decimal number support
- `AC` button to clear the complete input
- `DEL` button to remove the last entered character
- Clean and simple calculator interface
- Responsive web design

## 🛠️ Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling and layout
- **JavaScript** – Calculator logic and DOM interaction
- **Vercel** – Deployment
